Our Neuromorphic Solution

Unlike frame-based cameras that capture 30–60 frames per second with high latency, our event camera captures only pixel-level brightness changes asynchronously — just like the human retina. This gives us microsecond temporal resolution at a fraction of the power.

Works in total darkness & blinding sunlight
No motion blur — even at 240Hz+
Processes only what changes — not full frames
Runs on embedded hardware at <5W
System Architecture

How NeuroGuard Works

A biologically-inspired pipeline from raw events to drowsiness classification.

📷

Event Camera

A Dynamic Vision Sensor (DVS) captures per-pixel brightness changes as asynchronous events (x, y, t, p) with microsecond timestamps — no frames, no redundancy.

DAVIS346 / DVXplorer
→
🔲

Voxel Representation

Raw events are aggregated into temporal voxel grids with 5 time bins, producing spatiotemporal tensors that preserve the rich temporal structure of the event stream.

Shape: [5, H, W]
→
🧠

Spiking CNN Backbone

Two convolutional layers with LIF (Leaky Integrate-and-Fire) neurons process the voxel grid. Neurons fire only when needed — massively reducing computation vs. traditional CNNs.

SpikingJelly · LIF Neurons
→
⏱️

Temporal Attention + LSTM

An LSTM models temporal dynamics across frames while a soft-attention mechanism pinpoints the most informative time steps — focusing on blinks, head nods, and micro-sleeps.

Hidden: 256 · Dropout: 0.4
→
🚨

Drowsiness Classification

A fully-connected head outputs a binary prediction: ALERT 🙂 or DROWSY 😴. Class weights (0.3/0.7) correct for dataset imbalance, boosting recall for drowsy states.

2-Class · Cross Entropy Loss

Data Processing Pipeline

01
Frame Extraction Video frames extracted and converted to event representations via optical flow simulation
02
Voxel Grid Encoding Events binned into 5-channel temporal voxel grids of shape [5 × H × W]
03
Label Assignment Binary labels: 0 = Alert, 1 = Drowsy. Class weights 0.3/0.7 applied
04
DataLoader Batches of 4 sequences fed to the model. PyTorch VideoDataset class with shuffle
